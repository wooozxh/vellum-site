TOOLS / 六个工具

常用动作，都在面板里。

不追求「什么都能做」。只把设计师每天在 PS 里重复的那几步，收进一个常驻面板。

01

调色板

品牌色一键设为前景 / 背景 / 填充；自己的颜色存在本机，同色不重复。

02

素材库

任务库与通用库，多层目录、面包屑下钻；点一下置入当前画布。

03

表格生成

表格数据绑定图层，批量出稿。适合价签、名单、多图排版。

04

出图体检

导出前检查尺寸、色彩、字体等参数，先把问题拦在出图前。

05

导出审核版

带参数条导出成品图；大稿自动缩放；改完自动还原，原稿不动。

06

新建稿

从打好参考线的 PSD 模板开新稿；按规范建稿，含出血参考线。

BOUNDARY / 边界

它不做什么。

Toolbox 是出稿工具，不是第二个素材库。素材的归档、版本、工单和交付仍在 VellumDesk 里完成。

  • 不上传素材
    面板只读本机 Vellum 镜像与本机文件；没有云端。
  • 不替你存原稿
    导出审核版走副本，原稿保持不动；参数条只是导出层。
  • 不承诺修图
    它做取色、置入、表格、体检、审核版与新建稿，不做 AI 修图。
和 Desk 的关系：Desk 负责「东西在哪、属于谁、哪一版」；Toolbox 负责「在 PS 里把它用起来」。两个产品共用一套本地库，不互相替代。
AI-MCP 还在路上：面板里能看到规划中的入口，但方向未定案，当前版本不包含该能力。
