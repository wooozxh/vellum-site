v1.11.0
2026-10-17
WINDOWS · CURRENT

PSD 模板库、双视图、勾选批量

Desk 这一版把「找模板」和「批量干活」补齐。模板库只收 PSD / PSB，卡片直接显示尺寸、出血、色彩模式与参考线条数。

  • PSD 模板库：≤20 MB、必须读到画布尺寸；被拒文件留在原盘。
  • 卡片 / 列表双视图；列表支持全选、半选、Shift 连选。
  • 批量移动 / 复制到任务 / 序号改名 / 清除记录 / 删除。
  • 模板信息卡：512×512，参考线角标。
v1.10.0
2026-10-11
WINDOWS

PS 插件联动、通用素材库

Desk 的素材开始流进 Photoshop。通用素材库与任务库共用一套多层树；镜像自动同步，插件侧能看到最新状态。

  • 写镜像 manifest / task / brand / thumb，预建 handoff。
  • 通用素材库：多层分组、扫描认领、同步开关。
  • 镜像「变更后自动重写」：节流 + 串行锁。
v1.9.7
2026-10-10

占位封面、丢失角标修复

无成品图的任务生成通用占位封面；卡片右上角「丢失」角标与编辑按钮不再重叠。

v0.9.11–0.9.37
CURRENT
PHOTOSHOP

新建稿与 PSD 模板库

插件开始能「按规范开稿」：从打好参考线的 PSD 模板新建，而不是置入。模板缩略图改成 512×512 信息卡。

  • 「新建稿」入口：模板网格 + 打开成新稿（handoff → app.open）。
  • 按规范建稿：规范表 + presetJSON，含出血参考线。
  • 模板缩略图按 512×512 信息卡正方形显示。
  • 参考线坐标改百分比（PS 按百分比解释）。
v0.9.6–0.9.10
SERIES
PHOTOSHOP

素材库三段式与多层目录

素材库重做成「目录固定上 / 网格唯一滚动 / 插入固定下」的三段式；多层目录兼容到 5 层，面包屑下钻。

  • MAX_DEPTH 2→5，flattenBrand 真递归。
  • 面包屑下钻 + 整行子目录（dirlib）。
  • 插入面板瘦身：150px → 53px。
v0.9.0–0.9.5
SERIES
PHOTOSHOP

参数条改版 + CMYK 导出修复

审核版导出的参数条重做；CMYK 稿导出改走副本 + changeMode(RGB)，原稿零改动。

  • 参数条底色改用填充矩形层。
  • 取色换代：imaging.getPixels 使用 sourceBounds。
  • 复制副本再转 RGB，绕开 PS 存 PNG 不支持 CMYK 的限制。
v0.8.0
SERIES
PHOTOSHOP

导出审核版 + 成品图

审核版导出上线：带参数条导出成品图；大稿长边超过 4000 时等比缩放，并把比例印在参数条上。

  • 参数条：主题按底带平均亮度判定、竖线分隔、依据块右对齐带 logo。
  • 大稿缩放比例写进参数条，避免「看起来是原尺寸」的误判。
